SugarRush!! Candy Shop!

SugarRush online candy store that display a full inventory of candy and chocolates. Through the use of PHP, HTML, SQL and CSS, my project
allows users to browse a collection of products, view product information, register an account, update their account information, and 
delete their account when needed. Products can also be added without a user login; however, to updated, and removed from the
inventory a login is needed. The website is based off of a real life store that I used to work at. I was inspired by this project because I
wanted to create something that can actually be used, while still being fun, bright, and user-friendly.

The Technologies Used

* PHP
* SQL
* HTML
* CSS
* PDO

Local Setup Instructions

1. Download or clone the SugarRush files from my repository.
3. Create a MySQL database and import the required SQL tables for the `users` and `products` data.
4. Open Database.php and use your own information.
6. Put the completed files in a service like FileZilla and upload.
7. Make sure you have a server avalible to use like LampStack, and open the URL.
